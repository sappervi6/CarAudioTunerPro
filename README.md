Features: 
1. Calculate Current, Impedance, Voltage, Power(watt) Theoretical Max SPL from speaker Sensitivity and Input Power
2. Car radio system builder for options for speaker sizes and types in the dash, center dash. a-pillar,front and rear doors, rear deck and trunk.
3. AI powered architecture and system design guide. 
4. System TOpology Preview (WIP)
5. Sub Enclosure Port Calculator with net volume, tuning frequency, port diameter, and number of ports as inputs in order to get correct port length. 
6. Power requirmen review with Estimated Draw and Total system power calculated. 
7. Provides electrical upgrade recommendations and powwer cable gauge
8. Tone Sweep Generator ranging 20Hz to 20kHz
9. Six sine tone presets at 40, 80, 125, 400, 1000 and 3000  Hz
10. 10-20Hz autosweep
11. White Noise Generator
12. Pink Noise Generator
13. Sou dstage controls Front/Rear and Left/Right faders.
14. 16 Band equalizer with ISO frequency presets.
15. Parametric functionn to change frequencies on all bands as well as adjust the Q factor .1 - 10
16. Audio file upload to  tune the system
17. RTA- Real time analyzer for frequency tuning. Has options for peak hold, A,B,C and Z weighted measurements - requires use of phone or device microphone.
19. Three theme options, night and day mode, as well as the optoion to use the official colors of your favorite NFL team as the theme.

Installation:

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
